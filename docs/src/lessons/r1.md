# R1 — Five minutes

**Goal:** see what Leonardo is for, before learning anything about it.

Open the [browser REPL](https://lycogrypho.github.io/Leonardo/app/) in another tab. There is
nothing to install and nothing to configure: type the lines below at the `>` prompt and compare.

```scala mdoc:invisible
// BUILD-TIME SCAFFOLDING, NOT PART OF THE LESSON.
// `mdoc:invisible` removes this block from the published page, so a reader never sees it.
// It runs the transcripts below against a real REPL session when the site is built, which is
// what makes every answer on this page the library's own rather than something typed by hand.
// `Lesson` is docs/helper/scala/Lesson.scala -- on the docs build classpath only, never shipped.
import it.grypho.scala.leonardo.docs.Lesson
val lesson = Lesson()
```

## It is a calculator

```scala mdoc:passthrough
lesson.show("2 + 3 * 4", "(1 + 2)^10", "sin(pi/2)")
```

Precedence, brackets and the usual constants — `pi` and `e` are built in.

**Why `14.0` and not `14`?** Every ordinary number here is a decimal, so a whole result still
prints with its decimal part. That is worth noticing now rather than wondering about later, and
[R8](r8.md) shows how to get `14` — and exact fractions — when you want them.

## It is not only a calculator

Now ask for something a calculator cannot answer:

```scala mdoc:passthrough
lesson.show("derive(x^2 + 3x, x)")
```

There is no value of `x` here, so there is no number to give. Leonardo answered with **the
derivative itself** — an expression, not a measurement.

That is the whole idea, and it is the one thing worth taking from this lesson:

> When it can compute a number it does. When it cannot, it does the algebra and hands you back
> an expression.

Give it numbers and it goes the other way:

```scala mdoc:passthrough
lesson.show("integral(sin(x), x, 0, pi)")
```

Same command shape — `integral(what, variable, from, to)` — and this time everything was known,
so the answer is a number.

## It does work you would otherwise look up

```scala mdoc:passthrough
lesson.show("integral(x * exp(x), x)", "limit(sin(x)/x, x, 0)")
```

The first is an integration by parts, chosen without being asked. The second is the standard
first-year limit that `0/0` makes awkward by hand.

## And it draws

`plot` puts a curve on the page — **in the browser only**, which is why this page shows the
command rather than its result:

```text
> plot sin(x) x 0 6.28
(plotted 200 points)
```

Type it in the tab you opened. Then try `plot x^3 - 2x x -3 3`. The arguments are the same shape
again: *what*, *which variable*, *from*, *to*.

## Try it yourself

1. What is `2^10`?
2. Differentiate `x^3` with respect to `x`.
3. Integrate `cos(x)` from `0` to `pi`.

<details>
<summary>Answers</summary>

```scala mdoc:passthrough
lesson.show("2^10", "derive(x^3, x)", "integral(cos(x), x, 0, pi)")
```

The third is zero because the positive and negative halves of the cosine cancel over `0 … π`.
Note that `2^10` came back as `1024.0` — the decimal point again.
</details>

## What you learned

- An answer is **a number when one exists and an expression when it does not**. Nothing failed
  when you got an expression back.
- `derive`, `integral`, `limit` and `plot` all name the variable explicitly: `derive(f, x)`.
- Whole numbers print as `14.0`, because ordinary arithmetic here is decimal.
- `plot` is browser-only.
