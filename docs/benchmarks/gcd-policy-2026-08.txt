== threshold bound sweep ===============================================
Swept on BOTH arms.  On `exact` the bound is the only thing bounding growth, so
it is where a bad bound is dangerous.  At a finite precision it decides something
different: a bound BELOW the operand size implied by that precision fires on every
operation, which is Eager wearing a different name -- so the two arms pull opposite
ways and the default has to clear the higher of them.
